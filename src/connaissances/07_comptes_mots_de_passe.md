COMPTES ET MOTS DE PASSE WINDOWS — MANUEL DE SUPPORT

OBJECTIF
Ce document explique comment gérer les problèmes de connexion à Windows 11 : mot de passe ou code PIN oublié, différence entre compte local et compte Microsoft, compte bloqué, et bonnes pratiques. Il distingue clairement les deux types de comptes, car les solutions diffèrent.

LES DEUX TYPES DE COMPTE WINDOWS
Compte Microsoft : connecté à une adresse e-mail (Outlook, Hotmail, etc.). Le mot de passe est le même que celui du compte en ligne Microsoft. Il peut être réinitialisé depuis n'importe quel appareil via le site de récupération de compte Microsoft.
Compte local : existe uniquement sur cet ordinateur, sans lien avec une adresse e-mail. Si le mot de passe est perdu et qu'aucune question de sécurité n'a été définie, la récupération est beaucoup plus difficile.
Pour savoir lequel on utilise : Paramètres (touche Windows + I), Comptes, Vos informations. Si une adresse e-mail apparaît, c'est un compte Microsoft.

PROBLÈME : CODE PIN OUBLIÉ
Le code PIN est propre à l'appareil et différent du mot de passe du compte.
Solution : Sur l'écran de connexion, cliquer sur « J'ai oublié mon code PIN » sous le champ de saisie. Windows demande alors de vérifier l'identité avec le mot de passe du compte Microsoft, puis permet de définir un nouveau PIN. Si c'est un compte Microsoft, cette méthode fonctionne presque toujours.

PROBLÈME : MOT DE PASSE D'UN COMPTE MICROSOFT OUBLIÉ
Solution : Depuis un autre appareil (téléphone, autre ordinateur), aller sur la page officielle de réinitialisation du compte Microsoft. Saisir l'adresse e-mail du compte, puis suivre la procédure de vérification (code envoyé par e-mail ou par SMS au numéro associé). Définir un nouveau mot de passe. Ce nouveau mot de passe servira ensuite à se connecter à Windows. Comme la vérification passe par les coordonnées de secours, il est essentiel de les avoir tenues à jour.

PROBLÈME : MOT DE PASSE D'UN COMPTE LOCAL OUBLIÉ
La récupération dépend de la version de Windows.
Si des questions de sécurité ont été définies : sur l'écran de connexion, après une mauvaise saisie, cliquer sur « Réinitialiser le mot de passe » et répondre aux questions de sécurité pour en définir un nouveau.
Si aucune question de sécurité n'existe : il n'y a pas de moyen simple et officiel de récupérer le mot de passe. Les options sont d'utiliser un autre compte administrateur de la machine pour réinitialiser le mot de passe, ou en dernier recours de réinitialiser Windows (ce qui peut entraîner une perte de données). Dans ce cas, recommander de faire appel à un technicien et insister sur l'importance des sauvegardes.

PROBLÈME : COMPTE BLOQUÉ APRÈS PLUSIEURS TENTATIVES
Après plusieurs saisies erronées, Windows ou Microsoft peut bloquer temporairement le compte par sécurité.
Solutions : Attendre quelques minutes (le délai augmente avec le nombre de tentatives) avant de réessayer. Pour un compte Microsoft, vérifier sur le site qu'il n'y a pas d'activité suspecte signalée et déverrouiller le compte via la vérification d'identité. S'assurer que la touche Verrouillage majuscule (Caps Lock) n'est pas activée et que la bonne disposition de clavier est sélectionnée.

PROBLÈME : IMPOSSIBLE DE SE CONNECTER AU COMPTE MICROSOFT (ALORS QUE LE MOT DE PASSE EST BON)
Causes possibles : pas de connexion Internet au moment de la connexion, problème temporaire des serveurs Microsoft, ou mot de passe changé récemment sur un autre appareil.
Solutions : Vérifier la connexion Internet sur l'écran de connexion (icône réseau en bas à droite). Si le mot de passe a été changé ailleurs, utiliser le nouveau. En cas de blocage, le code PIN local permet souvent de se connecter même sans Internet.

CRÉER UN NOUVEAU COMPTE UTILISATEUR
Pour ajouter un utilisateur : Paramètres (touche Windows + I), Comptes, Autres utilisateurs, Ajouter un compte. On peut créer un compte Microsoft ou un compte local. Pour qu'un compte puisse installer des logiciels et modifier le système, le passer en administrateur : Autres utilisateurs, choisir le compte, Modifier le type de compte, Administrateur.

PASSER D'UN COMPTE MICROSOFT À UN COMPTE LOCAL (ET INVERSEMENT)
Paramètres, Comptes, Vos informations. Le lien « Se connecter plutôt avec un compte local » convertit le compte. L'inverse est aussi possible. Utile quand on veut un démarrage sans mot de passe en ligne.

BONNES PRATIQUES DE MOT DE PASSE
Utiliser un mot de passe d'au moins douze caractères mélangeant majuscules, minuscules, chiffres et symboles. Ne jamais réutiliser le même mot de passe sur plusieurs comptes. Tenir à jour les informations de récupération du compte Microsoft (adresse e-mail et numéro de téléphone de secours), car ce sont elles qui permettent de récupérer l'accès. Activer la vérification en deux étapes sur le compte Microsoft pour empêcher un accès même si le mot de passe est volé. Préférer un code PIN à un long mot de passe pour la connexion quotidienne : le PIN reste sur l'appareil et n'est pas transmis en ligne.

CHECKLIST RAPIDE
1. Identifier le type de compte (Microsoft ou local). 2. PIN oublié : « J'ai oublié mon code PIN » sur l'écran de connexion. 3. Compte Microsoft : réinitialiser depuis un autre appareil via le site Microsoft. 4. Compte local : questions de sécurité, ou autre compte administrateur. 5. Vérifier Caps Lock et la disposition du clavier. 6. Compte bloqué : attendre puis réessayer. 7. Tenir à jour les coordonnées de récupération.
