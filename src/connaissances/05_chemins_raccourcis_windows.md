CHEMINS EXACTS ET RACCOURCIS CLAVIER WINDOWS 11 — RÉFÉRENCE DE SUPPORT

OBJECTIF
Ce document donne les emplacements exacts des outils de Windows 11 et les raccourcis clavier utiles. Il sert de référence pour indiquer le bon chemin à l'utilisateur sans se tromper. Toujours donner le chemin exact tel qu'il est écrit ici.

RACCOURCIS CLAVIER ESSENTIELS
Ctrl + Maj + Échap : ouvre directement le Gestionnaire des tâches. C'est le raccourci le plus rapide.
Ctrl + Alt + Suppr : ouvre l'écran de sécurité (verrouiller, changer d'utilisateur, Gestionnaire des tâches, déconnexion).
Touche Windows + L : verrouille la session immédiatement.
Touche Windows + I : ouvre les Paramètres de Windows.
Touche Windows + E : ouvre l'Explorateur de fichiers.
Touche Windows + R : ouvre la boîte de dialogue Exécuter (pour taper une commande comme cmd, control, %temp%, ms-settings:).
Touche Windows + X : ouvre le menu des outils avancés (Gestionnaire de périphériques, Terminal, Gestion de l'ordinateur, etc.). Très pratique pour le support.
Touche Windows + D : affiche le Bureau.
Touche Windows + Pause : ouvre la page d'informations système (Paramètres, Système, Informations).
Touche Windows + Ctrl + Maj + B : réinitialise le pilote graphique quand l'écran reste noir ou figé.
Alt + F4 : ferme la fenêtre active.
Ctrl + Maj + N : crée un nouveau dossier dans l'Explorateur.

GESTIONNAIRE DES TÂCHES
Ouverture : Ctrl + Maj + Échap, ou clic droit sur le bouton Démarrer puis Gestionnaire des tâches.
Voir ce qui consomme les ressources : onglet Processus. Cliquer sur l'en-tête de colonne Processeur, Mémoire ou Disque pour trier par usage et repérer le programme responsable.
Forcer la fermeture d'une application figée : sélectionner l'application, puis bouton Fin de tâche en haut à droite.
Gérer les programmes au démarrage : onglet Applications de démarrage (anciennement onglet Démarrage). La colonne Impact de démarrage indique le poids de chaque programme. Clic droit sur un programme puis Désactiver.

PROGRAMMES AU DÉMARRAGE (deux chemins valides)
Chemin 1 : Gestionnaire des tâches (Ctrl + Maj + Échap), onglet Applications de démarrage.
Chemin 2 : Paramètres (touche Windows + I), Applications, Démarrage. Activer ou désactiver chaque application avec l'interrupteur.
Il n'existe PAS de menu « Outils d'optimisation du PC » dans Windows. Ne jamais l'indiquer.

LIBÉRER DE L'ESPACE DISQUE
Nettoyage de disque classique : touche Windows + R, taper cleanmgr, puis Entrée. Choisir le lecteur C, cocher les fichiers à supprimer.
Via les Paramètres : Paramètres (Windows + I), Système, Stockage. On y voit la répartition de l'espace et on peut lancer le nettoyage des fichiers temporaires.
Assistant Stockage (nettoyage automatique) : Paramètres, Système, Stockage, Assistant Stockage. L'activer pour que Windows vide automatiquement les fichiers temporaires et la corbeille.
Vider le dossier temporaire : touche Windows + R, taper %temp%, Entrée, puis supprimer le contenu du dossier.

DÉSINSTALLER UN PROGRAMME
Paramètres (Windows + I), Applications, Applications installées. Cliquer sur les trois points à droite d'une application puis Désinstaller. On peut trier par taille pour repérer les gros logiciels inutilisés.

APPLICATIONS PAR DÉFAUT ET NAVIGATEUR PAR DÉFAUT
Changer le navigateur par défaut sous Windows 11 : Paramètres (touche Windows + I), Applications, Applications par défaut. Taper le nom du navigateur voulu (par exemple Chrome ou Firefox) dans la barre de recherche des applications, cliquer dessus, puis cliquer sur le bouton Définir par défaut en haut de la page. Windows 11 associe alors automatiquement les types de fichiers web (HTTP, HTTPS, HTML) à ce navigateur.
Important : sous Windows 11, il n'y a PAS de case à cocher « Faire de ce programme un navigateur par défaut » suivie d'un bouton OK : c'était la méthode des anciennes versions de Windows. Le bon chemin actuel est Paramètres, Applications, Applications par défaut, puis le bouton Définir par défaut. Il n'existe pas non plus de menu nommé « Navigateurs par défaut » : la rubrique s'appelle Applications par défaut.
Changer une autre application par défaut (lecteur PDF, messagerie, photos) : même chemin, Paramètres, Applications, Applications par défaut, choisir le type de fichier ou l'application concernée.

WINDOWS UPDATE (mises à jour)
Vérifier et installer les mises à jour : Paramètres (Windows + I), Windows Update, puis bouton Rechercher des mises à jour.
Désinstaller une mise à jour problématique : Paramètres, Windows Update, Historique des mises à jour, Désinstaller des mises à jour. Choisir la mise à jour récente et la désinstaller.
Suspendre les mises à jour : Paramètres, Windows Update, Suspendre les mises à jour.

RÉCUPÉRATION ET RÉPARATION
Réparation du démarrage et options avancées : Paramètres (Windows + I), Système, Récupération, puis sous Démarrage avancé cliquer sur Redémarrer maintenant. L'ordinateur redémarre dans l'environnement de récupération où l'on trouve Dépannage, Options avancées, Réparation du démarrage.
Réinitialiser le PC (garder ou supprimer les fichiers) : Paramètres, Système, Récupération, Réinitialiser ce PC.
Point de restauration système : touche Windows + R, taper rstrui, Entrée. Cela ouvre l'assistant de Restauration du système. On peut aussi y accéder par le Panneau de configuration, Récupération, Ouvrir la restauration du système.
Il n'existe pas d'option nommée « Répair your PC » : le bon terme est Réparation du démarrage, dans l'environnement de récupération.

SÉCURITÉ WINDOWS (antivirus Microsoft Defender)
Ouvrir : Paramètres (Windows + I), Confidentialité et sécurité, Sécurité Windows, Ouvrir Sécurité Windows. Ou taper Sécurité Windows dans la recherche du menu Démarrer.
Lancer une analyse : dans Sécurité Windows, Protection contre les virus et menaces, Options d'analyse, choisir Analyse complète ou Analyse hors ligne de Microsoft Defender.
Vérifier la protection en temps réel : Protection contre les virus et menaces, Gérer les paramètres, vérifier que Protection en temps réel est activée.
Pare-feu : Sécurité Windows, Pare-feu et protection réseau.

GESTIONNAIRE DE PÉRIPHÉRIQUES (pilotes)
Ouvrir : clic droit sur le bouton Démarrer (ou touche Windows + X), puis Gestionnaire de périphériques. Ou touche Windows + R, taper devmgmt.msc, Entrée.
Mettre à jour un pilote : dérouler la catégorie (par exemple Cartes réseau), clic droit sur le périphérique, Mettre à jour le pilote.
Relancer un périphérique : clic droit, Désactiver le périphérique, puis de nouveau clic droit, Activer le périphérique.

PARAMÈTRES RÉSEAU
État du réseau : Paramètres (Windows + I), Réseau et Internet.
Résolution des problèmes réseau : Paramètres, Réseau et Internet, puis Utilitaire de résolution des problèmes, ou clic droit sur l'icône réseau dans la barre des tâches.
Réinitialisation complète du réseau : Paramètres, Réseau et Internet, Paramètres réseau avancés, Réinitialisation du réseau. Cela réinstalle les cartes réseau et remet tous les paramètres à zéro.
Voir l'adresse IP : Paramètres, Réseau et Internet, Propriétés de la connexion. Ou en ligne de commande avec ipconfig.

INVITE DE COMMANDES ET TERMINAL
Ouvrir en administrateur : clic droit sur le bouton Démarrer (touche Windows + X), puis Terminal (administrateur). Ou taper cmd dans la recherche, clic droit, Exécuter en tant qu'administrateur.
Beaucoup de réparations (sfc /scannow, ipconfig, chkdsk, DISM) exigent les droits administrateur, sinon elles échouent.

INFORMATIONS SYSTÈME (pour le diagnostic)
Voir les caractéristiques du PC : Paramètres (Windows + I), Système, Informations. On y trouve la version de Windows, la quantité de RAM et le type de processeur.
Outil détaillé : touche Windows + R, taper msinfo32, Entrée, pour le rapport complet d'informations système.
Type de disque (SSD ou HDD) : Gestionnaire des tâches, onglet Performance, sélectionner Disque, le type est indiqué.

BOÎTE EXÉCUTER : COMMANDES UTILES
Ouvrir Exécuter avec touche Windows + R, puis taper :
cmd (invite de commandes), control (Panneau de configuration), %temp% (dossier temporaire), cleanmgr (nettoyage de disque), devmgmt.msc (Gestionnaire de périphériques), rstrui (restauration système), msinfo32 (informations système), msconfig (configuration du démarrage), services.msc (services Windows), ms-settings: (Paramètres modernes), winver (version de Windows).

RÈGLE POUR L'ASSISTANT
Toujours donner un chemin présent dans ce document. Si un chemin précis n'est pas listé ici, décrire l'action en mots simples plutôt que d'inventer une suite de menus. Ne jamais inventer de nom de menu ou de bouton.
